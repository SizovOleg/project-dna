# Enforcement map — architect-cc-workflow

Каждое правило скилла с честной оценкой: насколько оно спецификация, а насколько намерение.

## Лестница ступеней

| Ступень | Механизм | Что это |
|---|---|---|
| 1 | Текст в скилле | Намерение |
| 2 | + размещение (начало/конец) | Намерение с лучшими шансами |
| 3 | + наблюдаемый след в артефакте | Наблюдаемое соблюдение |
| 4 | + регрессионный тест с порогом k/n | Измеренное соблюдение |
| 5 | + внешняя проверка, которая падает | Спецификация |
| 6 | + архитектурная невозможность | Жёсткое ограничение |

Спецификация начинается с 5. Всё ниже — намерение с разным качеством доказательств. Ступень определяется внешностью проверки, не формулировкой: «ЗАПРЕЩЕНО» в тексте ступень не поднимает.

Категории вне лестницы:
- `[эвристика]` — принципиально ступень 1, признака нарушения нет и не будет. Это нормально, если помечено.
- `[дисциплина архитектора]` — правило для человека, агентом не enforce'ится.

## Состояние после full-прогона (2026-08-18)

Прогнаны все 19 тестов набора. Итог: 18 взяли порог, T-SR-1 провалился 0/3,
T-G-1 (диагностический) эффекта не показал.

Два правила понижены по результатам замера, а не по рассуждению:

- **§5.1 (session manifest): 3 → 1.** Манифест не производится ни в одном
  прогоне. Правило было переформулировано из ненаблюдаемого «прочитай файлы» в
  наблюдаемое «выведи манифест с хешем» — наблюдаемость выросла, исполняемость
  нет.
- **§5.3 (размещение правил): 3 → 1.** Утверждение об эмпирике замером не
  подтверждено: при 460 строках инвариант соблюдался одинаково и в середине, и
  в начале с концом.

Понижение — не поражение скилла, а работа механизма: до сегодня обе строки
стояли на ступени 3 по общему соображению, теперь стоят на 1 по измерению.
Ступень определяется доказательством, а не намерением автора.

## Состояние после первого прогона (2026-08-18)

Ступень 4 фактическая для §3-verification, §3-рутина, §3.6, §11, §14.1 и
§15-частично. Конфликт §3 и §15 на флаге ❓ разрешён владельцем через §3.6
(критерий — встраивание значения); T-A-1 пересчитан на новой версии и дал 3/3.

Известные ограничения замера: исполнение через субагентов, а не `claude -p`
(CLI не стартует внутри сессии Claude Code); в CLAUDE.md фикстур продублированы
ключевые правила, поэтому измерена связка «скилл + типовой CLAUDE.md»; контроля
без скилла не было.
